# Custom Travel Blog Theme (WIP) 

A fully custom WordPress block theme designed and developed from scratch specifically for a travel blog. This theme leverages WordPress Full Site Editing (FSE) to provide a highly flexible, performant, and visually distinct foundation for travel content.

*Note: This project is currently in active development and is not yet ready for production use.*

## 🚀 Project Goals
- **Full Site Editing (FSE):** Completely block-based architecture using `theme.json` and block templates.
- **Custom Design:** Tailored specifically for travel blogging (rich media, destination grids, highly readable typography).
- **Performance Focused:** Minimal dependencies, leveraging native WordPress core blocks and custom CSS/JS only where necessary.

## 🛠️ Tech Stack
- **Environment:** WordPress (Block Theme / FSE)
- **Languages:** HTML, CSS, JavaScript, PHP
- **Design:** Custom templates, block patterns, and global styles driven by `theme.json`.
